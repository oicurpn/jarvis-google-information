# Jarvis Inventory Inbox — public information pages

Static app-information and privacy pages for a privately operated local assistant.

Publish only this directory's five allowlisted files: `index.html`, `privacy.html`,
`styles.css`, `.nojekyll`, and this `README.md`.

The repository must contain no backend code, credentials, OAuth client files,
tokens, private conversations, Google account content, inventory reports or archives.
GitHub Pages hosts only the descriptive website; Jarvis runs separately on the
owner-controlled Mac. This is not a public assistant registration service.

Pages use relative links, no JavaScript, no analytics, no forms and no third-party
fonts. Google/API access is never authorized through these pages.
